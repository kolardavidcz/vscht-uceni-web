# BI-PA1 source materials (not published wiki pages)

Raw inputs used to write the student support pages under  
`src/features/bioinformatics/content/1-semestr/bi-pa1/`.

| Path | Contents |
|------|----------|
| `original_notes/` | Author Moodle notes (voice / wording) |
| `exercises/` | Trainer KSI course 81 outlines |
| `students_wiki/` | Student tips (ODT/PDF) + `extracted/` UTF-8 text |
| `silabus.txt` | Official lecture outline |

Published pages are rewritten support material (kalendář-style), not a dump of these files.  
Do not move this folder under `src/features/bioinformatics/content/` — the content loader globs all `**/*.md` there into the app.
