Progtest Odkaz : https://progtest.fit.cvut.cz Progtest je automatický systém pro odevzdávání úkolů a semestrálních prací v předmětu BI-PA1 , BI-PA2 , BI-OSY , MI-PAR a další. Je hodně citlivý na jakékoliv nepřesnosti oproti zadání, a proto může být odevzdávání úkolu docela oříškem. Zde se prosím podělte o chyby, kvůli kterým vám Progtest úlohu nechtěl vzít, či čeho by se měli ostatní vyvarovat. Ve finální verzi by tato stránka měla fungovat jako jakýsi soupis chyb, které si vždy před odevzdáním můžou všichni projít a ujistit se, že je jejich program neobsahuje. Warning Level nastavte na More Warnings (odpovídá -Wall ) a do Command Line Additional Options napište -pedantic . Funguje jen pro obyčejný NetBeans C/C++ project, nikoliv u CIntru Pokud používáte funkce z math.h a gcc vám hlásí (například): undefined reference to `sqrt ', přidejte parametr -lm , takže celý příkaz vypadá (například): gcc -Wall -pedantic -lm -o main main.c Náhodná testovací data – lze si je vygenerovat například na Random.org . Testovací skript Pro testování očekávaných výstupů domácích úloh se velmi hodí celou činnost zautomatizovat, aby se člověk nemusel mořit s jednotlivými soubory z k tomu určeného archivu, který se nachází na progtestu u každé úlohy. K tomu mohou posloužit následující skripty pro testování na unixových systémech: Skript č. 1 #!/bin/bash # Zmente, pokud se vas binarni soubor jmenuje jinak PROGRAM =. / main # Pro vsechny soubory s nazvem "*_in.txt"... for TEST_FILE in * _in.txt; do echo -n ">>> Testing $TEST_FILE " # Zjisti rozdil mezi vystupem programu a vzorovym vystupem a uloz ho do promenne $DIFF DIFF = ` diff ${TEST_FILE/in/out} < ( $PROGRAM < $TEST_FILE ) ` if [ " $DIFF " == "" ] ; then echo "- OK" else echo "- FAILED" # Vypis obsah testovaciho vstupu (tedy data, ktera chybu zpusobila) echo "Input:" cat $TEST_FILE echo # Vypis rozdil mezi vystupem programu a vzorovym vystupem echo "Output diff:" echo " $DIFF " echo fi done Skript č. 2 Upravený předchozí script, input je zdrojový kód místo programu, doporučuju do ~/.bashrc dát následující hodnoty. Dále doporučuju změnit PATHTEST u obou, dle toho, kam rozbalujete vstupy a výstupy. Pokud chcete nějaké další přepínače, dejte je do proměnné PREPINACE. Stači poté spustit script ve složce se zdrojovým kódem. PROGTEST =main. * PATHTEST =~ / Stažené / CZE export PROGTEST export PATHTEST export PREPINACE #!/bin/bash CURRENT = $PWD [ $PROGTEST == "" ] && PROGTEST = "main.*" [ $PATHTEST == "" ] && PATHTEST = "~/Stažené/CZE" g++ -Wall -pedantic $PREPINACE $PROGTEST -o testprog if [ -f "testprog" ] ; then cd $PATHTEST for TEST_FILE in * in.txt; do echo -n ">>> Testing $TEST_FILE " DIFF = ` diff ${TEST_FILE/in/out} < ( $CURRENT / testprog < $TEST_FILE ) ` if [ " $DIFF " == "" ] ; then echo "- OK" else echo "- FAILED" echo "Input:" cat $TEST_FILE echo echo "Output diff:" echo " $DIFF " echo fi done rm testprog fi Zavedení skriptu do Fraye Kdyby byl s návody problém, pište na martinfury@seznam.cz Windows Nejdříve si stáhněte WinSCP , určitě se vám bude hodit, slouží ke kopírování na servery Připojte se skrz PuTTY a napište touch pgt chmod u+x pgt echo "alias progtest='~/pgt'" >> .bashrc bash joe pgt Zkopírujte si kód do schránky a v PuTTY zmáčkněte pravé tlačítko myši Upravte řádek s diff tak, aby odpovídal skriptu (ony vám udělají zpětné apostrofy prasárnu) a zmáčkněte Ctrl+K X Pakliže používate skript, co upravuje ~/.bashrc, tak napište echo "radek1" >> .bashrc echo "radek2" >> .bashrc ... bash Nyní už máte script na Frayi Pakliže testujete nový program, musíte nakopírovat vstupy a výstupy na fray skrz WinSCP Poté nakopírujte to, co skript požaduje (program nebo kód) Napište progtest Nezapomeňte upravit proměnné, popř script dle toho, co se píše u scriptu! Makefile Následuje Makefile pro automatizaci kompilace a testování (možno použít například s výše uvedeným bash skriptem). Uložte jej do souboru s názvem Makefile (dodržte velikost písmen) ve stejném adresáři, v jakém je váš zdrojový kód. Tento Makefile předpokládá, že máte svůj zdrojový kód v souboru main.c , že ho chcete zkompilovat do binárního souboru main a že ve stejném adresáři máte shell skript test.sh , který provádí testování vašeho programu proti testovacím datům. Používá se jednoduše: přepněte se do adresáře s Makefile , main.c a test.sh a do konzole napište: „ make “, nebo „ make build “ pro kompilaci programu, nebo „ make test “ pro kompilaci (pokud je nutná) a otestování programu. „ make clean “ smaže výsledek kompilace a „ make rebuild “ překompiluje program nezávisle na tom, jestli v main.c došlo k nějaké změně, nebo ne. Odsazení musí být tabulátory! all : build .PHONY : all build rebuild clean test build : main main : main . c $ ( CXX ) - Wall - pedantic - g - o $@ $< rebuild : make clean make build clean : \rm - f main # Do slozky main.dSYM nektere systemy ukladaji debug informace \rm - fR main . dSYM test : main ./ test . sh Jiné jednoduché ucelené řešení Aneb pokud se vám nelíbí předchozí skripty, jsou tu ještě další alternativy. Testovací skript Testovací skript, se kterým nemusíte rozbalovat vzorové archivy: #!/bin/bash die ( ) { echo $1 >& 2 exit 1 } [ $# -le 1 ] && die "Použití: sample.sh archiv binárka" [ ! -f "$1" ] && die "Archiv neexistuje." [ ! -f "$2" ] && die "Binárka neexistuje." [ ! -x "$2" ] && die "Binárka má špatná práva." archive = ` readlink -f $1 || which $1 ` binary = ` readlink -f $2 || which $2 ` tar tzf $archive | grep 'CZE/.*\.txt' -cq \ || die "S tímhle archivem si nevím rady." cd / tmp && mkdir -p progtest && cd progtest \ || die "Nemůžu se dostat do /tmp/progtest." # Well... let's test it now. tar xzf $archive CZE \ || die "Nepovedlo se mi rozbalit archiv." for file in CZE /* _in.txt; do echo "=== Ověřuju ${file%%_in.txt} ..." diff -u < ( $binary < ${file} ) ${file%%_in.txt} _out.txt done cd / tmp && rm -rf progtest \ || die "Nemůžu po sobě uklidit." Neukazuje vstupy, což je ponecháno jako cvičení čtenáři. Makefile Následuje Makefile pro GNU Make. Používám pojmenování cv*.c pro programy sepsané na cvičeních a ukol*.c pro domácí úlohy. Obě sady zdrojových souborů se nachízí ve složce společně se souborem Makefile. Ze zdrojových souborů vzniknou spustitelné soubory s tímtéž názvem, pouze bez přípony. Pro ekvivalent „make rebuild“ napište „make clean all“. SHELL = / bin / sh LIBS = - lm TARGETS = $ ( basename $ ( wildcard cv *. c ukol *. c ) ) all : $ ( TARGETS ) ukol %: ukol %. c $ ( CXX ) - o $@ - Wall - pedantic $< $ ( LIBS ) #-pg cv %: cv %. c $ ( CXX ) - o $@ - Wall - pedantic $< $ ( LIBS ) #-pg clean : @ rm - f $ ( TARGETS ) .PHONY : all clean TCC Ještě bych se rád zmínil o takové srandě jménem tcc (Tiny C Compiler), která umí pracovat jako interpreter C, takže můžete kompilaci úplně přeskočit. Je tu ale problém s tím, že je to čistě C kompilátor (narozdíl od g++ v progtestu), a není nejjednodušší ho dostat na fray. S ním stačí uvádět na začátku souboru: #!/usr/bin/tcc -run a přidělit zdrojovému souboru práva pro spouštění a můžete programy spouštět jako obyčejné skripty.
